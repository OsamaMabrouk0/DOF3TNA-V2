# 🎓 DOF3TNA-V2-UPDATES

**DOF3TNA-V2-UPDATES** is the update and content management repository for the [DOF3TNA-V2 educational platform](https://osamamabrouk0.github.io/DOF3TNA-V2/). It provides structured JSON files that define video playlists and update logic for the client-side application.

---

## 📚 Overview

This repository powers the content of **DOF3TNA-V2**, a web app that delivers curated educational video playlists categorized by subject. The platform helps students access learning material in an organized and efficient manner.

---

## 🔧 Features

- 📂 **Dynamic Playlist Management**  
  Each subject is mapped to a playlist URL defined in `playlists.json`.

- 🔄 **Update Checker**  
  The `update-DOF3TNA-V2.json` file enables the web app to check if a new update is available.

- 🌐 **Online-Ready JSON Architecture**  
  Optimized for direct use in frontend applications hosted on GitHub Pages or similar.

---

## 🗂️ File Structure

| File                        | Description                                                  |
|----------------------------|--------------------------------------------------------------|
| `playlists.json`           | Contains all subject names and associated video playlist URLs |
| `update-DOF3TNA-V2.json`   | Contains update version and status flags                     |
